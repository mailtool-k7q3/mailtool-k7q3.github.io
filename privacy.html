Privacy policy

This private tool acts only on its owner's own Google account.

It uses Gmail access only to send messages from that account, and to read and label the messages it sends. It does not read any other mail, and it does not share, sell or use any data for advertising.

Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

The owner can revoke access at any time at myaccount.google.com/permissions.
